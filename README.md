# 令牌库 (token-vault)

给 DeepSeek Harness 用的本机令牌管理插件：在侧栏的**令牌库**面板里保存 Git 令牌或其他 API 令牌，任意会话用 `vault_sh` 工具跑命令时把令牌注入**子进程环境变量**，令牌值不会出现在命令、会话记录、后台任务记录里。

## 能做什么

- **侧栏面板**：名称 / 令牌值 / 备注三项录入；列表显示令牌名、备注、`•••••••• · N 个字符`、更新时间；支持**搜索筛选**
- **只写不读**：面板可以新增、替换值、改备注、**改名**、删除（二次确认）；除显式的「导出」动作外，**没有任何接口返回令牌值**
- **导入 / 导出**：一键导出全部令牌为文件，可选密码加密（scrypt + AES-256-GCM）；明文导出需要额外输入 `EXPORT` 确认；导入支持明文 `.json` 与加密 `.tvault`，同名令牌可选「保留现有」或「覆盖」；另支持 **.env 文件批量导入**
- **会话零暴露**：agent 工具 `token_vault` 只返回令牌名、备注、长度和使用元数据；`vault_sh` 只把值放进子进程环境，命令文本里只有 `$GITHUB_TOKEN`，并可用 `tokens: [名字]` **只导出点名令牌**（最小权限）
- **输出洗值**：工具输出里出现的任何已存令牌值（含 URL 编码、base64、base64url、hex、JSON 转义形式）会被替换回 `{{token:名称}}`
- **占位符已禁用**：`{{token:名称}}` 不再做参数替换；出现在 `bash` / `run_code` 调用里会被拒绝并提示改用 `vault_sh`（其它工具、文档、提示词里它只是普通文本）
- **自动提示**：系统提示段落列出启用中的令牌名与备注（不含值）和 `vault_sh` 的用法，新会话不用先查询

### 1.5.0 新增

- **落盘加密**：设置主密码后整个库文件用 scrypt + AES-256-GCM 加密；Host 重启后处于上锁状态，面板输入主密码解锁，「立即上锁」随时清空内存中的值与密钥；加密前自动留一份明文备份，确认后可在面板删除
- **令牌启停**：每个令牌一个开关；停用的令牌不进 `vault_sh` 的环境、不出现在系统提示，洗值依然生效
- **使用审计**：`vault_sh` 每次导出会记录 `lastUsedAt` / `lastUsedBy`（面板显示「最后使用」），并可选写入 JSONL 审计日志（`~/.dsh/token-vault-audit.jsonl`，默认开，可在面板关闭）
- **审批模式**：面板开关打开后，每次 `vault_sh` 命令先请求你批准——默认弹**会话内卡片**（就在发起调用的会话里，一直等你处理）；也可在「安全」里改成**令牌库面板队列**（120 秒超时，卡片上带倒计时）
- **agent 保存请求**：agent 调 `token_vault({ action: "request-save", name, note, source })` 后，面板出现待确认条目，由用户粘贴令牌值并保存——agent 全程接触不到值
- **令牌健康检查**：编辑里给令牌设置检查 URL（如 `https://api.github.com/user`），面板「测试」按钮用它发一次请求（令牌经 `$TV_CHECK` 环境变量注入），2xx 有效、401/403 多半已过期；**GitHub / GitLab / Hugging Face / Slack / Cloudflare 名字的令牌不用配置**——没设 URL 时自动用内置端点测试
- **有效期提醒**：令牌可设有效期，列表里临近/过期有黄红标记，系统提示里附到期日期
- **重复值检测**：保存时若与已有令牌值相同会提示（防止一个令牌存两份、轮换时漏改）
- **前缀识别**：粘贴 `ghp_`、`glpat-`、`xoxb-`、`AKIA`、`sk-` 等前缀的值时自动预填名称与备注
- **.env 批量导入**：选 `.env` 文件 → 显示条数 → 选择同名策略导入；`export KEY=value`、引号包裹的值、注释行都能处理
- **改名**：不用删掉重输值，令牌名直接改

## 用法

1. 打开侧栏的 **令牌库**，填名称（如 `GITHUB_TOKEN`）、令牌值、备注，保存
2. 需要令牌时用 `vault_sh` 跑命令，令牌以环境变量形式存在于子进程：

   ```
   vault_sh({ description: "check GitHub identity",
              command: 'curl -sS -H "Authorization: Bearer $GITHUB_TOKEN" https://api.github.com/user' })
   ```

3. 命令文本、工具调用记录、后台任务标签、回执里都只有 `$GITHUB_TOKEN`；值只在该子进程的环境里
4. 只要某个令牌时：`vault_sh({ ..., tokens: ["GITHUB_TOKEN"] })`

**引号注意**：`$GITHUB_TOKEN` 用双引号或不加引号才会展开，单引号里 shell 不展开变量（`'Bearer $GITHUB_TOKEN'` 会原样传出去）。需要单引号的场合请改成双引号并转义内部引号。

Git 推送示例（令牌只走环境变量，不落进 URL 或 `.git/config`）：

```
vault_sh({ description: "push with token header",
           command: 'GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=http.extraHeader GIT_CONFIG_VALUE_0="Authorization: Basic $(printf \'x-access-token:%s\' "$GITHUB_TOKEN" | base64 -w0)" git push origin main' })
```

需要点名时，让 agent 调用 `token_vault` 工具列出当前可用的令牌（名称、备注、长度、启停状态、最后使用时间）。

## 导入 / 导出

面板底部是「导入 / 导出」区，**只由用户操作**，agent 没有对应工具。

**导出**

- 填「导出密码」→ 生成 `.tvault` 加密文件；留空 → 生成 `.json` 明文文件（必须在确认框输入 `EXPORT`）
- 加密参数：`scrypt(N=16384, r=8, p=1, keylen=32)` 派生密钥，`AES-256-GCM` 加密，16 字节随机盐、12 字节随机 IV，认证标签单独存放；密码错或文件损坏都会直接报错，不会解出半截数据
- 文件名形如 `token-vault-2026-11-07T09-30-00.tvault`，由浏览器直接下载
- 导出动作会记入审计日志

**导入**

- 选文件 → 填文件密码（明文文件留空）→ 选同名策略 → 导入
- `保留现有`：已存在的令牌完全不动，只新增；`覆盖`：同名令牌的值和字段被文件里的内容替换（保留原创建时间）
- 整批校验：只要有一个条目的名称/值不合法，**整个导入被拒绝**，不会出现导入一半的库
- 单次最多 500 条、请求体上限 2 MiB

**导入 .env**

- 选 `.env` 文件 → 面板解析并显示条数 → 选同名策略 → 导入
- 每行 `KEY=value`，忽略 `#` 注释与空行，支持行首 `export ` 与成对引号；名称不合法的条目会在结果里列出

明文导出文件格式：

```json
{
  "format": "token-vault/export",
  "version": 1,
  "exportedAt": "2026-11-07T01:30:00.000Z",
  "tokens": [{ "name": "GITHUB_TOKEN", "value": "…", "note": "…" }]
}
```

## 安全设计

- 面板的路由（list / save / delete / rename / export / import / import-env / settings / encrypt / unlock / lock / delete-backup / pending / resolve / check）挂在 GUI 的 HTTP 服务上，每条都先过 `connection` 的认证与来源围栏：未登录或跨站请求直接 `401`
- **导出是唯一返回值的那条路由**（`POST /token-vault/export`），只有用户在面板里点「导出」才会走到；agent 工具没有任何路径能调用它；明文导出还需输入 `EXPORT` 确认，缩小同源脚本静默导出的风险面
- **落盘加密**（可选）：主密码 scrypt 派生密钥 + AES-256-GCM 加密整个库文件；上锁状态下面板/工具都拿不到值，`vault_sh` 会明确报「库已上锁」；加密转换前自动备份明文并校验加密文件可解密回读，失败自动还原
- **审批模式**（可选）：开启后 `vault_sh` 等待你批准（默认会话内卡片，可选面板队列）；命令文本不含值，展示是安全的；拒绝/超时/跳过都不会执行
- 令牌值只存在于 Host 进程内存、本机文件、`vault_sh` 子进程环境，以及用户主动下载的导出文件里；工具结果和系统提示里都没有它
- **不再改写工具参数**：早期版本把 `{{token:名称}}` 在派发前替换成真实值，结果 bash 工具会把「替换后的完整命令行」写进会话日志的 `job/registered` 事件（作为 job 标签），并随 `job_output` / 任务回执回到会话里——后台任务和普通 bash 调用都会这样。1.1.0 起彻底去掉参数替换，改为环境变量注入
- `bash` / `run_code` 里出现占位符会被 `tools/pre-execute` 拒绝，避免「以为会被替换、实际原样执行」
- 洗值下限 8 个字符，避免误伤普通文本；较长的值优先匹配，防止前缀吞掉整串；hex 变体只对 ≤512 字符的值启用
- **停用令牌**不进 `vault_sh` 的环境，但洗值仍覆盖它的值（防回显）
- 名称受限为 `^[A-Za-z_][A-Za-z0-9_.-]{0,63}$`；名字里的 `.`、`-` 在导出环境变量时会换成 `_`
- 健康检查的 URL 与 header 在保存时校验（http(s)、无引号/反引号/反斜杠，header 只允许 `$TV_CHECK` 变量），命令由 Host 拼装，agent 无法注入
- 审计日志只记令牌名、会话、命令文本与状态码，从不记值；超过 10 MB 自动滚动为 `.1`

## 文件与配置

| 项 | 值 |
| --- | --- |
| 存储文件 | `$DSH_HOME/token-vault.json`（默认 `~/.dsh/token-vault.json`） |
| 覆盖路径 | 插件行配置 `config.file` 填绝对路径 |
| 审计日志 | `$DSH_HOME/token-vault-audit.jsonl`（默认开；`config.auditFile` 覆盖路径，面板开关控制写入） |
| 审批记录 | `$DSH_HOME/token-vault-approvals.json`（最近 50 条，`config.approvalsFile` 覆盖路径） |
| 加密备份 | `token-vault.json.pre-encryption.bak`（启用加密时生成，面板可删） |
| 权限 | `0600`；写入用临时文件 + `rename` 原子替换 |
| 名称规则 | 字母或下划线开头，最长 64 字符 |
| 令牌值上限 | 8192 字符 |
| 备注上限 | 500 字符 |
| 主密码 | 8–256 字符，scrypt(N=16384,r=8,p=1) + AES-256-GCM |

多会话、多 profile 共用同一个文件：令牌是「这个人」的凭据，而不是某个工作区的凭据。

## 安装

本包自带 `cordis.patch.yml`，作为本地 bundle 装进当前 profile 即可：把仓库目录交给 DeepSeek Harness 的插件管理（「插件」页面里的本地目录安装），它会插入 `token-vault` 这一行并启用。装好重启 `dsh web` 并刷新页面，侧栏就会出现「令牌库」入口（不再另外占用设置里的位置）。

- 主机半：`index.js`——存储（含加密）、HTTP 路由、`token_vault` / `vault_sh` 工具、占位符拦截、输出洗值、审计、审批队列、系统提示段落
- 浏览器半：`client.js`——侧栏令牌库面板（列表、搜索、启停、改名、待确认队列、安全设置、导入导出、健康检查）
- 资源：[`locale/en.json`](locale/en.json)、[`locale/zh.json`](locale/zh.json)、[`icon.svg`](icon.svg)

## 已知限制

- `vault_sh` 的 `timeoutMs` 只对前台生效：后台任务（`run_in_background: true`）没有超时，需要时用 `job_kill` 停止
- 会话内审批卡片没有超时：它会一直等你处理（工具调用中止时随之取消）；需要「到期自动放弃」请把审批方式设为面板队列（120 秒）
- `vault_sh` 不支持 `sandbox_permissions` 提权：它沿用当前会话的沙箱策略
- 把 `$GITHUB_TOKEN` 拼进 URL（如 `https://oauth2:$GITHUB_TOKEN@github.com/...`）时，git 可能把完整 URL 写进 `.git/config` 或错误信息；错误信息会被洗值，`.git/config` 不会——建议用上面的 `http.extraHeader` 写法
- 面板只用 Harness 的主题 token 做了配色适配，没有做截图级视觉回归
- **同源脚本风险**：导出路由返回全部令牌值，任何运行在这个页面同源下的脚本（包括其它客户端插件）都能在已登录前提下调用它；`EXPORT` 确认提高了门槛但不改变这一本质。不装来路不明的客户端插件是前提
- 加密导出与落盘加密的保护对象是「文件在磁盘/传输中被读取」或「Host 内存之外」；它不防本机被完全控制，也不替代吊销令牌。上锁只是清空内存，运行中的 Host 仍受本机账户安全约束
- 明文导出的文件就是明文凭据，导出后请自行保管或及时删除
- 加密前自动生成的明文备份（`.pre-encryption.bak`）在删除前仍是明文，请确认加密库可用后尽快删除
