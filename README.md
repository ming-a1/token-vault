# 令牌库 (token-vault)

给 DeepSeek Harness 用的本机令牌管理插件：在**设置 → 令牌库**里保存 Git 令牌或其他 API 令牌，任意会话用 `{{token:名称}}` 占位符引用；令牌值永远不会出现在会话记录里。

## 能做什么

- **设置里的管理面板**：名称 / 令牌值 / 备注 三项录入；列表显示令牌名、备注、`•••••••• · N 个字符`、更新时间
- **只写不读**：面板可以新增、替换值、改备注、删除（二次确认）、复制占位符；**任何接口都不返回令牌值**，面板自己也看不到
- **会话零暴露**：agent 工具 `token_vault` 只返回令牌名、备注、长度和占位符写法，拿不到值
- **执行前注入**：工具调用参数里的 `{{token:名称}}` 在派发前一刻才替换成真实值；会话日志、工具调用卡片里保留的仍是占位符
- **输出洗值**：工具输出里出现的任何已存令牌值（含 URL 编码形式）会被替换回 `{{token:名称}}`，`echo`、报错信息也泄不出去
- **未知名拒绝**：引用了库里不存在的令牌，调用直接失败并给出原因，不会带着字面占位符执行
- **自动提示**：系统提示段落会列出令牌名与备注（不含值），新会话不用先查询就知道能用哪些令牌
- 中英双语界面，跟随 Harness 的语言设置

## 用法

1. 打开 **设置 → 令牌库**，填名称（如 `GITHUB_TOKEN`）、令牌值、备注，保存
2. 在任意会话的工具调用里写占位符。例如在 bash 命令里：

   ```
   git clone https://oauth2:{{token:GITHUB_TOKEN}}@github.com/org/repo.git
   ```

3. 会话里只会看到占位符，真实令牌只出现在执行该命令的进程参数里

需要点名时，让 agent 调用 `token_vault` 工具即可列出当前可用的令牌（名称、备注、长度）。

占位符替换作用于**除 `write` / `edit` 之外**的所有工具调用参数，所以 `curl -H 'Authorization: Bearer {{token:XXX}}'` 这类场景直接可用。`write` / `edit` 被特意排除：文档和模板需要能原样写出占位符语法，而把真实令牌落进某个文件应该是用户在面板里的决定，不该是占位符的副作用。要在文件里生成真实值，用 bash（`printf` / 重定向）即可。

## 安全设计

- 面板的三条路由（list / save / delete）挂在 GUI 的 HTTP 服务上，每条都先过 `connection` 的认证与来源围栏：未登录或跨站请求直接 `401`，不进入任何处理逻辑
- 令牌值只存在于 Host 进程内存和本机文件里；HTTP 响应、工具结果、系统提示里都没有它
- 占位符替换发生在 `tools/execute` 阶段：工具派发前替换参数，日志里已记录的是原始占位符
- 洗值下限 8 个字符，避免误伤普通文本；较长的值优先匹配，防止前缀吞掉整串
- 名称受限为 `^[A-Za-z_][A-Za-z0-9_.-]{0,63}$`，不合法直接拒绝

## 文件与配置

| 项 | 值 |
| --- | --- |
| 存储文件 | `$DSH_HOME/token-vault.json`（默认 `~/.dsh/token-vault.json`） |
| 覆盖路径 | 插件行配置 `config.file` 填绝对路径 |
| 权限 | `0600`；写入用临时文件 + `rename` 原子替换 |
| 名称规则 | 字母或下划线开头，最长 64 字符 |
| 令牌值上限 | 8192 字符 |
| 备注上限 | 500 字符 |

多会话、多 profile 共用同一个文件：令牌是「这个人」的凭据，而不是某个工作区的凭据。

## 安装

本包自带 `cordis.patch.yml`，作为本地 bundle 装进当前 profile 即可：把仓库目录交给 DeepSeek Harness 的插件管理（「插件」页面里的本地目录安装），它会插入 `token-vault` 这一行并启用。装好刷新页面，设置里就会出现「令牌库」。

- 主机半：`index.js`——存储、HTTP 路由、`token_vault` 工具、占位符钩子、系统提示段落
- 浏览器半：`client.js`——设置 → 令牌库 页面
- 资源：[`locale/en.json`](locale/en.json)、[`locale/zh.json`](locale/zh.json)、[`icon.svg`](icon.svg)

## 已知限制

- **明文存储**：令牌以明文 JSON 存在本机 `0600` 文件里，没有加密。本机账户被攻破时令牌会暴露；需要更强保护可以再叠系统钥匙串或主密码
- 占位符是全参数替换（`write` / `edit` 除外），不要在不想被替换的模板里保留 `{{token:名称}}`
- 面板只用 Harness 的主题 token 做了配色适配，没有做截图级视觉回归
